# SEO & GEO (Generative Engine Optimization) Skill

An integrated methodology for creating content that excels across both **Traditional Search Engines (Google, Bing)** and **Generative AI Search Engines (Perplexity, ChatGPT Search, Claude, Gemini AI Overviews)**.

---

## Core Objectives

1. **Search Intent & Keyword Mapping**: Align content with the exact intent (informational, comparative, transactional) and long-tail query clusters.
2. **AI Citation Engineering (GEO)**: Deliver instant, high-density direct answers in the opening paragraphs, structured data tables, and question-phrased subheadings.
3. **CORE-EEAT Gating**: Ensure content satisfies the 80-item quality standard (Contextual clarity, Organization, Referenceability, Exclusivity, Experience, Expertise, Authoritativeness, Trust).

---

## The SEO/GEO Content Workflow

### Step 1: Query Intent & Keyword Architecture

1. **Primary Keyword**: The central high-intent search phrase (e.g., `autonomous AI coding agents`).
2. **Secondary & Long-Tail Variants**: 3–5 complementary queries and conversational questions (e.g., `agentic loops vs code autocomplete`, `how do AI agents verify code`).
3. **Target Audience Persona**: Define explicit reader background (e.g., senior software engineers, tech leads, engineering managers).

---

### Step 2: Content Structure & Heading Blueprint

Follow a strict hierarchy that facilitates both human scanning and machine parsing:

- **H1 Title**: Engaging, descriptive, and keyword-aligned (under 65 characters where possible).
- **Meta Description**: 140–160 character summary including the primary keyword and clear value proposition.
- **Direct Answer Block**: 2–3 sentence high-density summary answering the core query within the first 150 words.
- **Table of Contents**: Anchor links for articles exceeding 1,200 words.
- **H2 Sections**: Core topical pillars, using question phrasing for FAQ/problem-solving sections.
- **H3 Subsections**: Granular step-by-step points, code breakdowns, or sub-arguments.
- **Data & Comparison Tables**: At least 1 structured comparison table mapping options, criteria, or metrics.
- **FAQ Section**: 3–5 high-frequency questions formatted with structured answers.
- **Conclusion / Actionable Next Steps**: Clear synthesis and recommendations.

---

### Step 3: CORE-EEAT Quality Standard

Before content is published, review against the 8 core dimensions:

| Dimension | Key Focus | Standard Requirement |
| :--- | :--- | :--- |
| **C — Clarity** | Intent & Direct Answers | Core answer in first 150 words; defines jargon on first use |
| **O — Organization** | Visual & Structural Scannability | H1→H2→H3 hierarchy; bulleted lists; data tables; short paragraphs |
| **R — Referenceability** | Verifiable Data & Precision | ≥5 specific metrics with units; citations to primary sources; entity precision |
| **E — Exclusivity** | Information Gain | Novel framework, original diagrams, contrarian trade-offs, and synthesis |
| **Exp — Experience** | Firsthand Practical Insights | Real-world deployment observations, failure modes, and lessons learned |
| **Ept — Expertise** | Technical Depth | Accurate mechanics, architectural explanations, and principled rationales |
| **A — Authority** | Standards & Ecosystem Truth | Cites official documentation, established protocols (e.g. MCP, RFCs), and benchmarks |
| **T — Trust** | Balanced Transparency | Openly discusses trade-offs, costs, security implications, and limitations |
