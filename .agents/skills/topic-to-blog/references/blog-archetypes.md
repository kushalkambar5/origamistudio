# Blog Post Archetypes & Structural Blueprints

Select the appropriate archetype based on the user's topic, goal, and target audience.

---

## Archetype 1: Deep-Dive Technical / Conceptual Guide

**Best for**: Architectural explanations, deep dives into new frameworks, protocols, systems design, or paradigm shifts.

### Structure:
```markdown
# [Action-Oriented, High-Intent Title]
*Meta Description: 140–160 chars with primary keyword*

> **Quick Summary / Key Takeaway**: 2–3 sentence direct answer summarizing the core concept and when it applies.

## The Core Problem & Context
- Why traditional approaches hit a wall (concrete technical limitations).
- High-level overview of the paradigm shift.

## Architectural Breakdown / How It Works
- Core components and interaction flow.
- Visual diagram (Mermaid flowchart / architecture diagram).
- Concrete code / configuration examples.

## Key Performance Characteristics & Trade-offs
- Structured comparison table (Memory, Latency, Complexity, Tooling).
- Where this approach shines vs. where it is unnecessary overkill.

## Practical Implementation Guide / Step-by-Step
- Step 1, Step 2, Step 3 with verified snippets.
- Common gotchas and failure modes.

## Frequently Asked Questions
- 3–4 question-phrased H3s answering common long-tail queries.

## Summary & Next Steps
- Final synthesis and actionable recommendations.
```

## Archetype 2: Opinionated Thought Leadership & Strategic Essay

**Best for**: Industry trends, strategic shifts, contrarian viewpoints, developer culture, and technology analysis.

### Structure:
```markdown
# [Provocative / Thought-Provoking Title]
*Meta Description: Sharp summary of the central thesis*

> **The Central Thesis**: Bold, unambiguous statement summarizing the author's stance in 2–3 sentences.

## The Status Quo & Why It's Breaking
- Grounded observation from real-world practitioner experience.
- The hidden costs or unspoken friction of the current consensus.

## The Shift Nobody Is Talking About (The Meat)
- Deep analysis of underlying drivers (economics, ergonomics, organizational dynamics).
- Real data points, industry quotes, and empirical observations.

## Contrarian Analysis & Nuance
- What the optimists get wrong vs. what the cynics miss.
- Real-world failure modes and secondary effects.

## What This Means for Engineering Teams / Practitioners
- Concrete implications for tech stacks, hiring, architecture, and workflows.
- Pragmatic rubric: How to decide what to adopt today vs. what to ignore.

## The Verdict
- Memorable, grounded conclusion that leaves the reader with a clear perspective.
```

## Archetype 3: Comparative Breakdown & Benchmark Analysis

**Best for**: Tool evaluations, "X vs Y" comparisons, framework benchmarks, and technology selection matrices.

### Structure:
```markdown
# [Tool A vs Tool B: Comprehensive Evaluation & Decision Matrix]
*Meta Description: Clear comparison summary with target keywords*

> **Direct Decision Guide**: 2-sentence summary: "Choose Tool A if you need X; choose Tool B if your priority is Y."

## Executive Summary & Comparison Matrix
- Comprehensive comparison table (Features, Performance, Ease of Use, Pricing/TCO, Community).

## Deep Dive: Tool A
- Strengths, ideal use cases, architectural model, real-world limitations.

## Deep Dive: Tool B
- Strengths, ideal use cases, architectural model, real-world limitations.

## Hands-on Benchmark & Real-World Results
- Test methodology disclosure.
- Benchmark data, latency/throughput charts, or developer ergonomics comparison.

## Decision Framework: Which Should You Choose?
- Scenario 1: Early-stage startup / rapid prototyping.
- Scenario 2: Enterprise scale / strict compliance.
- Scenario 3: Legacy migration.

## Frequently Asked Questions
- 3–4 targeted questions matching search queries.
```

## Archetype 4: Case Study & Practical How-To Walkthrough

**Best for**: Tutorials, migration guides, real-world deployment stories, and workflow optimization.

### Structure:
```markdown
# [How to Build / Migrate / Optimize X: Step-by-Step Production Guide]
*Meta Description: Clear how-to value proposition*

> **Outcome Summary**: What you will build/achieve, prerequisites, and expected time investment.

## The Background & Objective
- Real-world scenario and end-state architecture.

## Prerequisites & Stack Setup
- Tools, dependencies, and environment configuration.

## Step-by-Step Walkthrough
- Step 1: Foundation & Setup
- Step 2: Core Implementation
- Step 3: Verification & Testing Loops
- Step 4: Production Hardening & Security

## Troubleshooting & Common Pitfalls
- Top 3 failure modes and exact fixes.

## Conclusion & Code Repository
- Summary and resources.
```
